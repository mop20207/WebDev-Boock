ENTENDÉ EL LENGUAJE

¿Qué es HTML?

La base de cada página

HTML (HyperText Markup Language) es un lenguaje de marcado que organiza el contenido de una página mediante elementos y atributos. No es un lenguaje de programación: describe qué significa cada parte del contenido, por ejemplo un título, un párrafo, una imagen, un enlace o un formulario.

01EstructuraDefine títulos, secciones, listas, enlaces, imágenes y formularios.
02SignificadoSu semántica ayuda a navegadores, buscadores y tecnologías de asistencia.
03En equipoSe combina con CSS para la presentación y JavaScript para la interacción.
COMPATIBILIDAD

¿En qué navegadores funciona?

HTML moderno

Los elementos fundamentales de HTML funcionan en todos los navegadores modernos: Chrome, Firefox, Edge, Safari y Opera. Las diferencias aparecen en elementos o atributos más nuevos, formatos multimedia y funciones específicas. Internet Explorer quedó obsoleto y no soporta correctamente muchas funciones actuales.
