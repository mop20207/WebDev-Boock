# Referencia técnica de WebDev Book

Esta carpeta conserva una guía técnica del estado del proyecto para retomarlo en el futuro.

## Por dónde empezar

1. Abrí [index.json](index.json): explica el contenido de todos los documentos y el orden de lectura.
2. Leé [project-overview.json](project-overview.json) y [architecture.json](architecture.json): explican qué es la aplicación y cómo se conectan sus partes.
3. Consultá [content-inventory.json](content-inventory.json) para conocer los contenidos y módulos incluidos.
4. Usá [storage-and-offline.json](storage-and-offline.json) y [android-build-status.json](android-build-status.json) antes de cambiar almacenamiento, módulos descargables o Android.
5. Revisá [file-impact-map.json](file-impact-map.json) antes de modificar archivos.
6. Terminá con [resume-guide.json](resume-guide.json) para conocer el estado y cómo continuar.

## Alcance y mantenimiento

Los documentos describen el repositorio en el commit de referencia indicado en `index.json`. No son configuración de la aplicación ni reemplazan los catálogos fuente, manifiestos o scripts de validación. Cuando cambien módulos, rutas, almacenamiento o workflows, actualizá los documentos afectados y la fecha/commit de referencia. Los elementos marcados como pendientes no deben interpretarse como funcionalidades ya disponibles.
