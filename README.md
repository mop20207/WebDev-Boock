# WebDev Book

Enciclopedia interactiva y responsive para aprender HTML, CSS y JavaScript.

## Estructura del proyecto

```text
WebDev-Boock/
├── index.html
├── pages/
│   ├── html.html
│   ├── css.html
│   └── javascript.html
├── css/
│   ├── global.css
│   ├── home.css
│   ├── html.css
│   ├── css.css
│   └── javascript.css
├── js/
│   ├── app.js
│   ├── navigation.js
│   ├── theme.js
│   ├── search.js
│   └── editor.js
├── data/
│   ├── html.json
│   ├── css.json
│   └── javascript.json
└── assets/
    ├── icons/
    └── images/
```

## Descripción
- `index.html`: página de inicio.
- `pages/`: una página independiente por lenguaje.
- `css/`: estilos globales y estilos específicos.
- `js/`: navegación, tema, búsqueda, editor e inicialización.
- `data/`: catálogos de temas en JSON que se ampliarán progresivamente.
- `assets/`: iconos e imágenes.

## Estado
Estructura modular inicial. Los temas están listados y se desarrollarán progresivamente con explicaciones, ejemplos, ejercicios y demostraciones.
