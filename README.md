# WebDev Book

Enciclopedia interactiva de desarrollo web para aprender y consultar HTML, CSS y JavaScript.

## Objetivo
Reunir explicaciones, ejemplos prácticos y pequeños laboratorios de código en una aplicación web responsive, pensada primero para móviles.

## Tecnologías
- HTML
- CSS
- JavaScript
- LocalStorage / IndexedDB para preferencias y progreso local

## Secciones previstas
- Inicio
- HTML
- CSS
- JavaScript
- Ejercicios y proyectos
- Favoritos y progreso
- Laboratorio con editor HTML, CSS y JavaScript y vista previa
