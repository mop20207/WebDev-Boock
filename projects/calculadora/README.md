# Calculadora básica

Operaciones de suma, resta, multiplicación y división, con decimales, porcentaje y cambio de signo.

## Detalles
La calculadora guarda el operando anterior, operador y valor actual. Usa delegación de eventos para manejar todos los botones desde un contenedor.

## Probá
`8 ÷ 2`, `5.5 × 2`, `9 − 12` y división por cero. Para usos financieros reales se necesita precisión decimal.
