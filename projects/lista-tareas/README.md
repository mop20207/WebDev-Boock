# Lista de tareas

CRUD con creación, marcado, borrado, filtros y persistencia en `localStorage`.

La interfaz se crea con `createElement()` y `textContent` para no insertar el texto que escribe el usuario como HTML. La clave de almacenamiento es propia del proyecto.

## Probar
Agregá tareas, completá algunas, filtrá, recargá y borrá las completadas. El almacenamiento es local a este navegador y no sincroniza dispositivos.
