# API REST propia

API CRUD con Express y TypeScript. Los datos están en memoria y se borran al reiniciar.

## Ejecutar
`npm install`, luego `npm run dev`. Ejecutá `npm test` para las pruebas de contrato.

## Rutas
GET /api/tasks, GET /api/tasks/:id, POST /api/tasks, PATCH /api/tasks/:id y DELETE /api/tasks/:id.
