# Tienda online con Next.js

Catálogo y carrito de ejemplo más un Route Handler que valida el pedido y vuelve a calcular importes en el servidor.

## Ejecutar
Usá Node.js 22.18+ (o 24.11+), copiá `.env.example` como `.env.local`, instalá dependencias y ejecutá `npm run dev`.

**No procesa pagos ni persiste pedidos.** Los precios no se aceptan desde el navegador. Para una tienda real, agregá base de datos, stock transaccional, autenticación y proveedor de pagos.
