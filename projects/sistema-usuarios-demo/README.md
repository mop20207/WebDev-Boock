# Sistema de usuarios — demo local

Directorio didáctico con alta, búsqueda, cambio de rol y baja. Los datos se guardan en `localStorage`.

**No es autenticación ni autorización.** Cualquier persona con acceso al navegador puede modificar perfiles y roles. No almacena contraseñas, no protege rutas y no debe usarse para datos reales. Los permisos reales se verifican siempre en backend.
