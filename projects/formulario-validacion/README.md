# Formulario con validación

Valida nombre, correo y mensaje en el navegador y muestra errores junto a cada campo.

## Aprendizajes
- Asociación de `label` e `input`.
- Eventos de envío y prevención de recarga.
- Expresiones regulares y validación por reglas.
- `aria-invalid` y mensajes `aria-live`.

**Importante:** la validación del cliente no sustituye la validación del servidor. Este formulario no transmite ni guarda datos.
