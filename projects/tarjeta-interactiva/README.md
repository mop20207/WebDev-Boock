# Tarjeta interactiva

Tarjeta semántica que despliega información adicional sin navegar a otra página.

## Probar
- Activá el botón con mouse, toque y teclado.
- Observá cómo cambia `aria-expanded`.
- Confirmá que el contenido tiene un encabezado propio.

## Conceptos
`article`, `section`, `hidden`, eventos `click`, `aria-controls` y `aria-expanded`. Los datos del perfil son ficticios.
