# Gestor de proyectos full-stack

Base Next.js App Router, TypeScript, Prisma y PostgreSQL.

## Ejecutar
Configurá PostgreSQL y `.env.local`, luego `npm install`, `npx prisma migrate dev --name init` y `npm run dev`.

No incluye autenticación ni permisos por proyecto. Antes de usar datos reales, agregá autorización y pruebas.
