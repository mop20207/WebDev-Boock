# Aplicación del clima

Consulta la geocodificación de Open-Meteo y luego pide las condiciones actuales de las coordenadas.

## Aprendizajes
- `fetch()`, `async/await` y JSON.
- Encadenamiento de solicitudes HTTP.
- Estados de carga, éxito y error.
- Codificación de parámetros URL.

La ciudad se envía al proveedor para resolver coordenadas y obtener el pronóstico. La demo no la guarda. Requiere Internet; verificá los términos del proveedor antes de un uso comercial.
